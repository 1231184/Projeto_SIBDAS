Sobre o Projeto MediCore

Uma solução académica desenvolvida no âmbito da unidade curricular de Sistemas de Informação e Base de Dados Aplicados à Saúde (SIBDAS) do ISEP.

O Desafio

A gestão eficiente do inventário de equipamentos médicos é um dos pilares fundamentais para o bom funcionamento de qualquer unidade de saúde. A falta de controlo sobre o ciclo de vida, localização e estado de manutenção dos dispositivos pode comprometer gravemente a prestação de cuidados clínicos e a segurança dos doentes.

A Solução

O MediCore Systems foi concebido como uma resposta tecnológica a este desafio. Trata-se de uma plataforma web que centraliza a informação, permitindo uma monitorização rigorosa do inventário, acompanhamento de manutenções, gestão documental e controlo de fornecedores de forma integrada e intuitiva.

Enquadramento Académico

Este sistema foi desenvolvido integralmente no ano letivo de 2025/2026 como projeto de avaliação da unidade curricular de SIBDAS, lecionada no Instituto Superior de Engenharia do Porto (ISEP).

O desenvolvimento do MediCore Systems permitiu a aplicação prática de diversos conhecimentos teóricos, englobando múltiplas fases da engenharia de software:

  • Modelação e estruturação de bases de dados relacionais (MySQL).
  • Desenvolvimento de interface gráfica responsiva (HTML5, CSS3 e Bootstrap).
  • Implementação de lógica de negócio no servidor (PHP).
  • Gestão de controlo de versões e repositórios (Git/GitHub).
